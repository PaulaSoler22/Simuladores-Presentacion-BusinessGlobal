# CompanyGame BusinessGlobal - Presentación Interactiva

## 🎮 Descripción

Presentación interactiva HTML para el simulador de negocios **BusinessGlobal** de la plataforma **CompanyGame**. Esta presentación está diseñada para demostrar las capacidades del simulador a universidades colombianas.

## 🚀 Inicio Rápido

Simplemente abra el archivo `index.html` en un navegador web moderno:

```bash
# En macOS
open index.html

# En Linux
xdg-open index.html

# En Windows
start index.html
```

## 📋 Contenido de la Presentación

La presentación contiene **12 slides** interactivos:

1. **Portada** — CompanyGame
2. **BusinessGlobal** — Introducción al simulador
3. **Cartelera de Simuladores** — Catálogo completo
4. **Entorno del Simulador** — Descripción del entorno
5. **Tipos de Fábrica** — Opciones de fábricas
6. **Áreas de Decisión** — Decisiones que toman los estudiantes
7. **Los 5 Competidores** — Competidores en la simulación
8. **Cuadro de Mando** — Dashboard de control
9. **Valor de la Compañía** — Métricas de valoración
10. **Métodos de Implementación** — Uso en el aula
11. **Preguntas Frecuentes** — FAQ
12. **Cierre** — Agradecimiento

## 🎛️ Controles

| Control | Acción |
|---------|--------|
| `→` Flecha derecha | Siguiente slide |
| `←` Flecha izquierda | Slide anterior |
| Botón ▶ | Siguiente slide |
| Botón ◀ | Slide anterior |
| Swipe izquierda | Siguiente slide (móvil) |
| Swipe derecha | Slide anterior (móvil) |

## 🛠️ Tecnologías

- HTML5
- CSS3 (con variables CSS y animaciones)
- JavaScript vanilla (ES6+)
- Google Fonts (Montserrat, Open Sans)
